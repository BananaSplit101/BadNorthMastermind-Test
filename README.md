# Bad North Multiplayer: test build

A test build of [Bad North Multiplayer](https://github.com/BananaSplit101/BadNorthMastermind), version 1.0.14.1: the
normal mod with a few extras for the mastermind. It is binary only: the release holds a single `BadNorthMP.dll` that
replaces the normal mod's DLL, so the normal mod has to be installed first.

- Everyone in a lobby has to be on the same build. This one (1.0.14.1) only plays with itself.
- To go back to the normal build, reinstall the normal mod. Its in-game updater also replaces this build when the
  next public version comes out.

Same license as the main mod (MIT).
